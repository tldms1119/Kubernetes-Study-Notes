## 📘 Kubernetes-Study-Notes
This repository contains my personal study notes, hands-on commands, and YAML manifests while preparing for the Certified Kubernetes Application Developer (CKAD) exam using the Udemy course - Kubernetes Certified Application Developer (CKAD) with Tests.

## 🎯 Study Goals

- Understand core Kubernetes concepts clearly
- Practice both imperative and declarative workflows
- Build reusable YAML manifests
- Prepare efficiently for the CKAD exam
